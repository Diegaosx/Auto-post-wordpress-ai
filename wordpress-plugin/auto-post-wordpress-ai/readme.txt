Sincronização automatizada e publicação de artigos com Inteligência Artificial via REST API segura.

== Description ==
O plugin Auto Post WordPress AI conecta seu portal WordPress diretamente ao painel Auto Post AI, permitindo o recebimento automático de artigos minerados de portais de notícias e reescritos por Inteligência Artificial (Gemini, OpenRouter, Llama).

== Installation ==
1. Faça o upload da pasta `auto-post-wordpress-ai` para o diretório `/wp-content/plugins/` ou envie o arquivo ZIP diretamente pelo painel do WordPress em Plugins > Adicionar Novo > Enviar Plugin.
2. Ative o plugin através do menu 'Plugins' no WordPress.
3. Acesse o menu 'Auto Post AI' no painel lateral do WordPress.
4. Cole a sua Chave de Licença (API Key) obtida no painel Auto Post AI e salve as configurações.
5. Clique em "Testar Conexão Agora".
